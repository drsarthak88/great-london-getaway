# Security Policy

## Reporting a problem

If you find a security or privacy problem in The Great London Getaway, please
**report it privately** rather than opening a public issue:

1. Go to the repository's **Security** tab.
2. Choose **Report a vulnerability** (GitHub private vulnerability reporting).
3. Describe the problem, how to reproduce it, and which device and browser you used.

Reports are reviewed as soon as possible. Please give a reasonable amount of time
for a fix before sharing details publicly.

## Supported versions

Only the latest version, published at
https://drsarthak88.github.io/great-london-getaway/, is supported. Fixes are made
there and are not backported.

## What the game stores

This is a game for children, so privacy matters:

- The game has no accounts, adverts, analytics or tracking.
- Progress (coins, outfits, best scores, settings) is saved **only on your own
  device**, in the browser's local storage. It is never sent anywhere.
- The **Share** button uses your device's own share sheet (or copies a message);
  nothing is sent unless you choose to share it.

If future versions add online features such as accounts or online scores, this
policy will be updated before they are released.
